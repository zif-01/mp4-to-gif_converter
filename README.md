# 🎮 Discord GIF Converter

Полнофункциональный конвертер MP4 в GIF с графическим интерфейсом, оптимизированный для Discord.

## ✨ Особенности

- 🎨 **Современный графический интерфейс** с поддержкой drag & drop
- ⚡ **Автоматическая оптимизация** под ограничения Discord (10MB, 10 секунд)
- 📊 **Три уровня оптимизации**: качество, баланс, размер
- 🎞️ **Поддержка обрезки видео** по времени
- 📁 **Пакетная обработка** множества файлов
- 📝 **Детальный лог** конвертации
- 🔄 **Предпросмотр** перед конвертацией (один файл)
- 🎯 **Точный контроль** FPS и разрешения
